
# Clinic Pharmacy Batch & Expiry Tracker

A Java-based inventory management system designed for clinic pharmacies to track medicine batches, monitor expiry dates, manage stock levels, and handle batch recalls efficiently.

## Features

- Medicine Management - Add, update, and view medicine records
- Batch Tracking - Track medicines by batch number with manufacturing and expiry dates
- Expiry Alerts - Automatic alerts for medicines nearing expiry
- Stock Management - Real-time stock-in/stock-out tracking with ledger records
- Batch Recall System - Quickly identify and recall defective batches
- User Management - Role-based access for pharmacy staff

## Tech Stack

- Language: Java
- Database: MySQL
- JDBC Driver: MySQL Connector/J 9.7.0
- IDE: IntelliJ IDEA
- Architecture: DAO Pattern
